# Platform extras

Keycloak SWIM Role SPI is deployed automatically by the `swim-core-infra` Helm chart (pre-install Job from GitHub Release). Configure `keycloak.spi` in `infra/swim-core-infra/chart/values.yaml`.

Source project: [swim-developer-add-ons/keycloak-swim-role-spi](https://github.com/swim-developer/swim-developer-add-ons/tree/main/keycloak-swim-role-spi).
